# skills

[![skills.sh](https://skills.sh/b/DevJuanP/skills)](https://skills.sh/DevJuanP/skills)

A collection of reusable skills for AI coding agents (OpenCode, Claude Code, Cursor, Copilot, and any agent that reads the `SKILL.md` standard).

## Install

```bash
npx skills add DevJuanP/skills --skill ship
```

List all available skills in this repo:

```bash
npx skills add DevJuanP/skills --list
```

## Skills

- **[ship](skills/ship/)** — Commit and push current git changes with a Conventional Commits message in Spanish. Use when you just want to ship the current changes.
